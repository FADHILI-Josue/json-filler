How it works

                
No setup. It reads your JSON and picks a fitting value for each field.

                

                    
1
Reads the value
An email becomes a new email, a UUID a new UUID, a link a new link.

                    
2
Reads the field name
When the value is just "string", names like firstName or userId decide.

                    
3
Keeps numbers similar
Same sign, digits and decimals, so 29.99 stays a price.
